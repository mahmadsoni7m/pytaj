# Муҳаррики Python

Интихоб: **Chaquopy 15.0.1** (Python 3.11). Он Python-ро дар дохили APK ҷойгир мекунад, бинобар ин иҷро офлайн аст. ABI: arm64-v8a, armeabi-v7a, x86_64 (APK калонтар мешавад).
Мувофиқатии нусхаҳо (AGP 8.5.2 / Gradle 8.7 / Kotlin 1.9.24 / Chaquopy 15.0.1) бо ҳуҷҷатҳои расмӣ **санҷида нашудааст**: сабаб — интернет дар муҳити сохтан нест. Агар сохтан ба хатои Chaquopy расад, нусхаи плагинро дар `build.gradle.kts` тағйир диҳед.

## Чӣ тавр иҷро мешавад
`ChaquopyPythonRunner` дар `Dispatchers.IO` `runner.run_code(...)`-ро даъват мекунад (UI банд намешавад). Ҳамзамон танҳо як иҷро.

## Маҳдудиятҳо (санҷиши ҳадд, на sandbox-и пурра)
| Ҳадд | Амалисозӣ | Маҳдудият |
|---|---|---|
| Вақт (5 сония) | трейсер дар ҳар сатри Python | Амалҳои дарозмуддати C (масалан `10**10**10`) ва `except BaseException: pass` дар даври беохир метавонанд онро дур зананд |
| Қатъ (Stop) | флаги `request_stop`, ки трейсер месанҷад | Ҳамон маҳдудият |
| Ҳаҷми натиҷа (20 000 аломат) | нависандаи маҳдуд | — |
| Шабака/subprocess | import-ҳои socket, ssl, subprocess, ctypes, http, urllib ва ғ. барои коди корбар манъ | Манъ танҳо барои import-и мустақими корбар; os ва ғайра боз мемонанд |
| Файл | `open()` танҳо дар папкаи кэши барнома (`cache/learner`) | `os.listdir` ва ғайра дастрасии васеътар доранд |
Барои қатъи боэътимод дар оянда бояд иҷрогар дар раванди алоҳида (`android:process`) гузошта шавад ва ҳангоми timeout раванд кушта шавад. Ин ҳоло амалӣ нашудааст.

Китобхонаҳои иловагии pip (numpy ва ғ.) насб нашудаанд.

## Санҷиш
`runner.py` дар Python 3.12-и компютер бо санҷишҳо тафтиш шуд: print, SyntaxError, IndentationError, ZeroDivisionError (рақами сатр), timeout, маҳдудияти натиҷа, input(), import-и манъшуда, open() берун аз папка, RecursionError, sys.exit. Дар Android/Chaquopy санҷида **нашудааст**.
