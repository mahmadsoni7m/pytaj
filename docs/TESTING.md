# Санҷишҳо
- `python tools/validate_content.py` — курс (бе Android).
- `gradle :app:testDebugUnitTest` — unit-тестҳо дар `app/src/test`: баҳодиҳии машқҳо, пешрафт/силсила, боркунии курс ва мазмуни воқеӣ, JSON-и вайрон, ёрии хатоҳо, парси натиҷаи runner.
- Санҷишҳои Room, ViewModel, UI ва Python дар Android (`androidTest`) ҳанӯз навишта нашудаанд.
Дар CI: ҳарду санҷиши аввал пеш аз сохтани APK иҷро мешаванд ва агар хато шавад, workflow мешиканад.
